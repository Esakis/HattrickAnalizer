# Preferencje użytkownika

- Nie uruchamiaj aplikacji ani jej serwerów i nie otwieraj przeglądarki, jeśli nie jest to niezbędne do wykonania zadania.
- Przy code review i ocenie użyteczności zacznij od analizy kodu, szablonów i istniejących testów. Samo zlecenie review nie oznacza potrzeby uruchomienia aplikacji.
- Jeśli uruchomienie okaże się konieczne, najpierw wyjaśnij konkretny powód.
